# HTML Foundations Assessment — Explanations

### 1. What is `<!doctype html>`?
It tells the browser that the document uses modern HTML.

### 2. What is the `<html>` element?
It is the root element that contains the entire HTML document. The `lang="en"` attribute identifies English as the page's language.

### 3. What is the `<head>` element?
It contains information about the webpage, such as its character settings and title. Most of this information is not displayed as page content.

### 4. What is the `<body>` element?
It contains the content visitors see on the webpage, such as headings and paragraphs.

### 5. What is the `<title>` element?
It sets the webpage title displayed in the browser tab.

### 6. What is an HTML element?
An element is a part of an HTML document, usually consisting of an opening tag, content, and a closing tag.

### 7. What is an HTML tag?
A tag is markup written inside angle brackets, such as `<p>` or `</p>`.

### 8. What is an attribute?
An attribute provides additional information about an element. For example, `lang="en"` specifies the language in the opening `<html>` tag.

### 9. What is nesting?
Nesting means placing one HTML element inside another element.

### 10. What is a void element?
A void element does not have a closing tag. For example, `<meta charset="utf-8">` is a void element.
